\subsubsection{Secure Aggregation Procedure in Cluster Rounds}
\label{sec:secure-aggregation-sap}

Each cluster-level training round executes the Secure Aggregation Procedure (SAP) so that the elected aggregator learns only the average of the members' model deltas while every contributor's raw tensor remains hidden. Plaintext sharing would expose gradients that can leak labels or even reconstruct raw samples, so embedding SAP directly into cluster orchestration preserves the privacy boundary proved by Bonawitz et~al.~\cite{SecureAggregation} without altering the rest of the pipeline~\cite{DLG,Geiping2020Inverting,Melis2019Leakage}.

SAP enforces a quorum because the server can only reconstruct pairwise masks and self-masks after collecting at least $t$ shares for every secret (via threshold secret sharing)~\cite{SecureAggregation,shamir1979share}. Practically, the aggregator waits for messages in each of the four rounds and aborts if the threshold is unmet, mirroring the ``abort if $|u_i| < t$'' guard in~\cite{SecureAggregation}. The quorum guarantees that no coalition smaller than $t$ can strip another client's mask and that the unmasking phase has enough information to produce a valid mean; otherwise the round is canceled to avoid partial disclosure or incorrect aggregates~\cite{SecureAggregation}.

If a cluster round aborts, all members restart that round: they resume local SGD from the previous checkpoint, re-advertise keys, and rerun SAP. The loop may repeat several times, amplifying the amount of local computation per logical round (\emph{Round Amplification})\label{def:round-amplification}, but it preserves the invariant that only quorum-protected aggregates leave the cluster~\cite{SecureAggregation,MansouriFTSA}. Nodes that dropped mid-protocol and later return simply wait for the next committed cluster CID, keeping the transcript consistent—only survivors of that run contribute, whereas late arrivals stay passive until the following attempt~\cite{SecureAggregation,MansouriSoK}.

Permanent failures are more problematic because quorum may never be reestablished. When that happens, fan-out processes declare their cluster CID stale during higher-level aggregation (Section~\nameref{subsubsec:system-architecture-hierarchy}) and forward locally trained tensors so state or nation aggregators can still incorporate recent progress despite the missing secure aggregate~\cite{MansouriFTSA}. Meanwhile, active nodes continue polling upstream anchors and applying state/nation models, ensuring that even a stalled cluster benefits from global updates while operators address the membership loss.
